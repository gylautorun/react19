# DOCX 9.9 报告工作台

访问 `/docx`，可直接在网页纸张上编辑标题、摘要、分析段落和指标表格。旁边的属性区可调整纸张、方向、页边距、分析分栏、强调色、封面形状和水印文字。编辑结果实时同步到图表，并可导出 `.docx`。生成过程在浏览器本地完成，不上传报告内容。

项目将 `docx` 精确固定为 `9.9.0`。导出模块在点击下载时动态加载，普通路由无需载入文档生成代码。

当前在线编辑器围绕内置报告模板工作，可以修改表格行及图表数据；暂不打开或回写任意已有 DOCX。下载后的文件仍是原生 Word 文档，文字、表格、图表、形状、水印和页面布局可继续在 Word 中编辑；图表附带可编辑的数据表。

## 文档结构

- 封面、指标和分析各为一个 Word 分节。各节共享页眉、动态页码页脚及纸张设置；分析节可选单栏或双栏。
- 封面包含原生 DrawingML 形状。指标节使用 Word 表格和可编辑的柱状图；图表数据同时写入嵌入的 Excel 工作簿。
- 可选水印使用 `docx/watermarks` 的 `TextWatermark` 放在页眉中，跨页重复。
- `docx/layout` 的 `estimatePageNumbersWith({ guess: true })` 写入页码，`layoutDocument` 给出导出后的估算页数。

网页纸张是直接编辑当前模板的界面，不是 Word 渲染器。实际分页受 Word 版本、字体和用户编辑影响。布局估算对不支持的绘图或字体可能采用近似值；界面会在这种情况下标记“部分版面采用估算”。

## 验证

运行 `pnpm typecheck`、`pnpm lint` 和 `pnpm build`。浏览器打开 `/docx`，分别切换横向、窄边距、双栏、图表和水印并下载。可解压生成文件检查 `word/charts/chart1.xml`、`word/embeddings/*.xlsx`、`word/header*.xml` 与 `word/document.xml` 中的分节和形状。
